I built a fraud model monitoring data pipeline using Python, PySpark, and SQL.

The project simulates how payment transaction data can be processed and monitored after fraud models score transactions.

What it does:
- Reads transaction-level fraud scoring data
- Calculates Transaction Review Rate (TRR)
- Creates score bucket distributions for drift monitoring
- Runs data quality checks for nulls, duplicates, and invalid scores
- Produces clean outputs for dashboarding or alerting

Tech used:
Python, PySpark, SQL, Git, batch processing, data quality validation

Why I built it:
I wanted to create a practical data engineering project that connects ETL, fraud analytics, model monitoring, and production-style validation instead of building a basic tutorial pipeline.
