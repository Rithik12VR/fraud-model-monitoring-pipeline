# GitHub Setup Commands

Run these commands from inside the project folder.

```bash
git init
git add .
git commit -m "Initial commit - fraud model monitoring pipeline"
```

Create a new empty repository on GitHub, then run:

```bash
git branch -M main
git remote add origin https://github.com/<your-username>/fraud-model-monitoring-pipeline.git
git push -u origin main
```

Replace `<your-username>` with your GitHub username.
